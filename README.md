# 顕微鏡の部品あて（kenbikyo-buhin）

顕微鏡の使い方の手順や部品の説明（目でのぞくレンズ・明るさのむらを直す鏡・ピントを合わせるねじ など）を読んで、顕微鏡の部品（接眼レンズ・対物レンズ・反射鏡・しぼり・調節ねじ）を当てる1日5問の学習ゲーム。正解したら「何をする部品？」（拡大して見る・明るさを調節する・ピントを合わせる）も選ぶ。中学1年理科「顕微鏡の使い方」。
